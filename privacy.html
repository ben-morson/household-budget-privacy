Household Budget — Privacy

Household Budget is a private, self-hosted budgeting tool used by a single household. It is not offered to the public.

Google Calendar access

With the household's permission, the app uses the Google Calendar API (scope calendar.events) to create, update and delete reminder events — for example "Shop around: Car Insurance" — on one calendar chosen by the household. It only modifies events it created itself. It does not read, store or share any other calendar data.

Data storage

Budget data and the Google access token are stored only on the household's own server. Nothing is sold, shared with third parties, or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
